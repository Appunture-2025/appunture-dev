# 🔄 Configuração de Ambiente - Appunture

## Arquivos de Ambiente

### `.env` (Atual - Local Development)

Configuração para desenvolvimento local conectando ao backend em `localhost:8080`

### `.env.production.backup` (Backup)

Configuração de produção conectando ao Cloud Run

## 🔄 Como Alternar Entre Ambientes

### Para Desenvolvimento Local:

```powershell
Copy-Item ".env.local" ".env" -Force
```

### Para Produção (Cloud Run):

```powershell
Copy-Item ".env.production.backup" ".env" -Force
```

## 🌐 URLs Configuradas

### Local:

- Backend: http://localhost:8080/api
- Firebase Storage: appunture-tcc.firebasestorage.app

### Produção:

- Backend: https://appunture-backend-756244484248.us-central1.run.app/api
- Firebase Storage: appunture-tcc.firebasestorage.app

## 📱 Testando no Celular

Se você estiver testando no celular físico, troque `localhost` pelo IP da sua máquina:

1. Descobrir IP:

```powershell
ipconfig | Select-String "IPv4"
```

2. Atualizar .env:

```
EXPO_PUBLIC_API_BASE_URL=http://192.168.X.X:8080/api
```

Exemplo:

```
EXPO_PUBLIC_API_BASE_URL=http://192.168.1.10:8080/api
```

## ⚠️ IMPORTANTE

Sempre que alterar o `.env`, você precisa:

1. Parar o Expo (`Ctrl+C`)
2. Limpar cache: `npx expo start --clear`
3. Recarregar o app no dispositivo
